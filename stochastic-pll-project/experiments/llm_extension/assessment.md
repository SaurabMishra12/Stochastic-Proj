# LLM extension: scientific gate and full-split design

Status: proposed, no API inference executed, no cost incurred by this project. The synthetic oscillator results are not evidence of improved LLM reasoning. A physical phase is not identified in an embedding or answer string. The candidate controller therefore does not yet satisfy a defensible phase-signal validation gate for a full paid benchmark. The full paid extension is deferred, not replaced by a small pilot.

## Dataset and separation
GSM8K official repository https://github.com/openai/grade-school-math supplies 7473 training and 1319 test problems, directly downloaded and counted on 2026-11-13; both JSONL files and their SHA256 are preserved in dataset_manifest.json. Use the entire official test split exactly once after tuning only on an explicitly held-out development subset of the training split. Gold answers never enter model-visible prompts. Record repository commit and SHA256 of JSONL. HotpotQA is optional and requires a separate scientific rationale.

## Comparison contract
Three identical agents, fixed roles/prompts/model/deployment/temperature/output cap across independent, full communication, fixed sparse, disagreement-triggered, stochastic-controller methods. One candidate independent answer call per agent and three refinement calls plus one fixed adjudication call per item/method: a proposed seven logical calls per method, 35 per item for five methods. Call-matched independent agents make private refinements without receiving peers. Deduplicate/cache only where identical requests are deliberately paired and report that dependency; do not count cached repeated results as independent observations. Randomize method order, use distinct reproducible seeds where supported, record retries separately from logical calls, and checkpoint every request/result. Analyze correctness paired by test item; McNemar/paired bootstrap accuracy differences with a multiplicity plan. Cost/token/message/latency distributions use independent problems; include failures in denominators under a preregistered exclusion policy.

## Phase-signal gate
Development only: define phase from an identifiable cyclic decision state before outcomes are inspected, specify periodicity and invariance, and compare held-out predictive performance with ordinary answer and semantic disagreement. An embedding angle depends on basis and lacks natural 2pi periodicity. Jensen-Shannon divergence requires actual comparable normalized answer distributions and cannot be manufactured from single answers or unrelated token vocabularies. Test incremental information via cross-validated nested prediction/log loss, permutation negative controls and calibrated uncertainty. A phase mapping without a useful held-out gain terminates the PLL-to-LLM claim. Generic disagreement control can still be studied as a different proposal.

## Full-scale budget formula
Let N be the counted official test size. Five methods x seven logical calls =35N calls for one seed: 46,165 logical calls for N=1319. Robustness to message dropout (e.g.0,.1,.3) and corruption (0,.1,.3), if fully crossed, multiplies this by9; five benchmark seeds multiplies by5. Set those factors before approval, rather than silently treating one run as the complete extension. Let I and O be mean input/output tokens per logical call, Pin/Pout deployment-specific dollars per million. Estimated base dollars =35N*(I*Pin+O*Pout)/1e6. Report conservative token ceilings as well as expectations; requests above budget stop before dispatch. Rates are deployment/account-specific and cannot be inferred from a generic model name. Azure endpoint/deployment/API version/key are absent from the four canonical environment variables checked locally; other secret stores were not enumerated. Do not print or place secrets in reports.

## Approval gate before any remote call
Verify dataset count/hash and selected deployment pricing and quotas; calculate all method/seed/robustness calls and token ranges; configure retry caps/backoff, request idempotency, spending ceiling, exclusion accounting and resume hashes. Present actual costs and obtain explicit user approval. Credentials should be supplied through secure environment configuration, never pasted in the report. No rate-limit, dollar total, or available deployment is asserted without that information.

For the measured N=1319, base logical calls=46,165. With planning assumptions I=2000 and O=800 tokens per call, base expected token totals are 92,330,000 input and 36,932,000 output. These are workload assumptions, not observed usage or deployment limits. A 9-condition robustness cross and five seeds would imply 2,077,425 calls, 4.15485 billion input tokens and 1.66194 billion output tokens under the same assumptions. No dollar estimate is defensible until a deployment and its pricing are selected.
